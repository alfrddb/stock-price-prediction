# 📈 Stock Price Predictor

A web application built with Python, PyTorch, and Streamlit that utilizes a Long Short-Term Memory (LSTM) deep learning model to forecast stock closing prices based on historical data fetched from Yahoo Finance.

🌐 **Live Demo:** [Try the live app here!](https://stock-price-prediction-vgwc7vyqgqifxfrvce4xw7.streamlit.app/)

---

## Features

- **Interactive Web Interface:** Built with Streamlit to allow users to dynamically customize stock tickers, historical date ranges, sequence lengths, and training epochs.
- **Real-Time Financial Data:** Automatically downloads historical market data via the yfinance API.
- **Deep Learning Forecasting (LSTM):** Implements a custom recurrent neural network architecture in PyTorch tailored for sequential time-series prediction.
- **Live Model Training & Metrics:** Train the neural network directly in the browser with a real-time progress bar, loss tracking, and visual comparison charts between actual and predicted prices.

---

## Tech Stack

- **Python** – Core programming language
- **PyTorch** – Deep Learning framework for building and training the LSTM model
- **Streamlit** – Framework for the interactive web application UI
- **Pandas & NumPy** – Time-series data manipulation and sequence preprocessing
- **Scikit-Learn** – Data normalization and evaluation
- **Matplotlib** – Financial data and prediction visualization
- **yfinance** – Market data retrieval

## How to Run Locally

If you wish to run the application locally on your machine:

1. Clone the repository:
   `git clone https://github.com/alfrddb/stock-price-prediction.git`

2. Move into the directory:
   `cd stock-price-prediction`

3. Install dependencies:
   `pip install -r requirements.txt`

4. Run the app:
   `streamlit run main.py`
